# 共享业务资产

当前架构以用户最新要求为准：Mac 原生实现；Windows 未来用 C#／.NET 8 独立实现。共享的是规格、数据合同、素材和验收行为，不是一个跨平台 Swift 可执行文件。

- `CoreSpec.md`：供 C# 使用的规格草稿。
- `Swift/PetCore`：原有判定规则与动作时序的唯一规范源。
- `Swift/Core`：业务控制器、抽象接口、请求路由、消息结构、事件与纯字节分行器。
- `Assets/BustV3`：11 组原透明动作素材。
- `Tests/Swift`：业务、协议、序列与分行验收样例。

这里不包含 AppKit 调用、系统文件描述符读取、C 头文件、窗口句柄或平台桥接依赖。`Foundation`／`Dispatch` 仅用于 Swift 参考实现；C# 应按规格复现行为。
