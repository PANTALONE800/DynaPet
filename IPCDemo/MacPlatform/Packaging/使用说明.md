# DynaPet原生包

适用 macOS 14+，本包架构见文件名。完整解压后把 DynaPet.app 拖到「应用程序」，双击启动。它是原生 GUI 应用，不需要终端、Electron 或 Node.js。

菜单栏「DynaPet」可显示桌宠、摸摸、切换 75% / 100% / 125% 大小和退出。环境感知、状态变化与 11 组动作由 Swift 核心运行。当前分层版本尚未迁移原应用的消息监听、OCR 与登录启动管理。

包内动态库位于 Contents/Frameworks，已从内到外进行 Ad-hoc 签名，未经 Apple 公证。分享给别人时，对方可能需要在「隐私与安全性」批准首次打开。

仅在确认包来源可信、且明确需要清理隔离属性时，可在对方自己的终端运行：

```sh
xattr -dr com.apple.quarantine /Applications/DynaPet.app
```

这不是日常启动步骤。退出应用后删除 DynaPet.app 即可卸载。

`--ipc` 仅供可选宿主使用；此模式读写标准流并监测宿主生命周期。正常双击不会因 stdin 关闭而退出。
